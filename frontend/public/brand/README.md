# THOBX official logo artwork

Lossless WebP encodings of official homepage assets retrieved on 2026-10-31:

- thobx-logo-white.webp: https://thobx.bh/wp-content/uploads/2025/08/logo-w.png
- thobx-logo-gold.webp: https://thobx.bh/wp-content/uploads/2025/08/logo-g.png

Each image is transparent and 826 × 346. Decoded RGBA pixels match the original PNGs exactly. The sidebar uses the gold bilingual logo on forest green in both themes. The favicon embeds the gold WebP, showing its central emblem through an SVG viewport on forest green. See docs/thobx-theme.md for provenance and app adaptations.
