# Cancellation and return UI

Refreshed for bounded return quantities and refund visibility on 24 October 2026 (Asia/Bahrain). Captured from the actual local application with an isolated PostgreSQL database, synthetic customer and transaction data, and a local authentication harness. The garment examples include their original urgency fee. Browser checks cover typed quantity limits, remaining quantities after partial returns, and immediate and deferred refunds.
